## 费用与当前限制

按 2026-11-09 的中转站公开最高档报价、未计缓存折扣和账户组，规划题的参考开销为 HY3 0.007729、GLM 0.0004612；审查题分别为 0.000818、0.0043324。这是站点参考单位，不是实扣账单。单题结果表明模型单价较低不保证每次总成本或耗时都较低。

此前 DeepSeek 的真实长任务曾出现摘要额度问题：一次请求明确发送 `max_tokens=128`，返回的单帧用量报告输出 3198。两种新模型本次 4 个长短摘要样本均在 4K 以内，但样本不足以证明网关对所有请求都严格执行上限。正式比较应保留超额、截断、失败和未知用量，不能用失败任务的较短耗时宣称速度优势。

测试过程所有真实调用计入同一批次请求账本。生产专用冒烟测试会话曾意外出现在本地诊断输出中，已单独注销并验证失效；模型 API Key 与其他会话未改变。
