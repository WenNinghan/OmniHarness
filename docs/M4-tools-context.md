# M4 工具、授权与上下文

本机部署步骤见 [M4 预览部署](M4-preview-deployment.md)，已执行的测试见 [实施记录](M4-implementation.md)。这是一套单用户开发预览，不是完整 v0.1 发行包。

## 从界面使用

1. 在输入框上方选择工作项目，或登记本机绝对路径。初始授权为只读；需要改文件时勾选“允许修改原项目”。被排除的凭据、符号链接和框架数据不进入工具范围。
2. 选择 Agent 任务与模型方案。任务开始时冻结模型、上下文策略、工具授权和工作区版本。
3. Agent 可读取、搜索项目，通过提供原文件 SHA256 的补丁创建或替换文件。用户同时修改文件会触发冲突，不直接覆盖。
4. 命令每次运行前创建过滤快照，在固定 Linux 工具镜像执行。命令修改的快照不会回写原项目。正常编辑使用补丁工具；不要让命令代替原目录编辑。
5. 若登记时选择命令逐次审批，运行详情显示待批准的确切命令。批准沿原 Run 的检查点恢复。暂停状态下批准后仍需手动继续；补充要求会使旧审批失效。
6. 运行详情可查看实际参数、快照 ID、退出码和完整日志。完整工件按页读取；模型也可通过 `artifact_read` 读取同一 Run 的工件。

工具只在显式关联工作区的 Agent Run 开启。普通聊天和未关联项目的旧流程不会自动获得文件或命令能力。默认禁止工具容器出网，也没有 Docker socket、模型 Key 或原项目挂载。

## 暂停、失败与结果未知

暂停在模型和工具边界生效，等待中的审批会释放 Worker 的执行位置。已开始的工具先收尾或确认回收，不能仅凭前端按钮变化就认为容器已停止。同一工作区的写入任务互斥，全实例最多两个工具操作同时执行。

已保存的工具结果可以恢复复用。发生请求已派发、结果未保存的情况时，系统保留“待核对”，不重新执行来补齐记录。取消任务不会回滚已修改的文件。

终止后的未知命令或补丁可以在详情中明确确认后“核对并释放占用”。命令必须确认原沙箱已不存在；这仅证明资源已回收，退出结果仍为未知。补丁必须匹配原操作回执和当前文件版本。核对记录统一为 `UNVERIFIED`，不会变成成功，也不会重放。缺少沙箱 ID、回执不完整或文件已变化时仍拒绝释放，需要人工处理。MCP 外部副作用无法通过本地容器不存在证明完成，暂不提供这一自动核对入口。

## 上下文和记忆

“高级设置”中的上下文配置属于模型配置版本，运行时冻结。默认输入整理目标为估算 16,000 tokens，达到 80% 时尝试摘要；保留最近约 4,000 tokens，单次摘要输出上限为 4,000 tokens。主回答的 100,000 输出配置保持不变。这里的估算不是供应商精确 tokenizer，未知模型总窗口不伪装成已知。

主请求会计入系统指令、工具 Schema 和保护的当前任务。若已填写模型总窗口，还会预留主回答上限与安全余量；无法容纳时明确停止。把输入目标设得很小可能无法容纳摘要提示、完整工具交换或当前要求；不会通过截断原任务、拆开工具调用配对来继续。

摘要复用 LangChain 的 SummarizationMiddleware；实际调用仍经过本框架的预算、控制与持久账本。摘要保存来源消息 ID、摘要版本、用量和完成状态。摘要调用算入总预算；没有费用数据时费用保持未知。失败、截断或失联摘要不会替换原文，历史聊天始终保留。

实测中，Pro 的一次摘要返回 `finish_reason=length`，4000输出 tokens 中含2987推理 tokens，公开摘要未完成，任务按 `SUMMARY_INCOMPLETE` 停止。主回答100K不代表摘要也有100K额度。遇到这一情况可在模型高级设置中调整摘要输出及输入目标后发起新 Run；已有 Run 使用冻结配置，系统不会静默增加额度或重发可能已计费的请求。原文件改动和已完成的测试记录仍保留。

当前是任务与会话上下文管理，尚无跨项目长期记忆、自动用户画像或向量记忆库。供应商推理字段不混入跨角色摘要；公开阶段产物与最终回答分别保存。

## 受信任 MCP 服务

通过 `OMNI_MCP_CONFIG_FILE` 指定本机 JSON 配置。仅支持官方 MCP Python SDK 2.1.0 的 Streamable HTTP。配置在 Run 开始时冻结，执行前再次核对当前配置；配置变化要求新建 Run，不会静默获得新权限。没有运行时安装陌生插件或任意 stdio 命令入口。

```json
{
  "schema_version": 1,
  "version": 1,
  "servers": [{
    "id": "my-service",
    "url": "https://your-service.example/mcp",
    "enabled": true,
    "credential_ref": "my-service.key",
    "tools": [{
      "name": "lookup",
      "description": "查询已授权资料",
      "side_effect": "read",
      "input_schema": {"type": "object", "properties": {"query": {"type": "string"}}, "required": ["query"]}
    }]
  }]
}
```

示例地址不可直接使用。将服务实际 `tools/list` 返回的完整输入 Schema 复制到本地注册；框架要求二者一致。凭据文件保存在独立 secrets 目录，普通配置仅保存引用。远程服务要求 HTTPS；本机测试允许 loopback HTTP。

`side_effect` 可为 `read`、`write` 或 `external`，省略时视为 `external`。只有明确注册的 read 工具免审批，其他调用需要逐次确认。远端 `readOnlyHint` 不能扩大本地授权。实际工具响应丢失后保持未知，不隐式重试；远程服务仍属于用户明确选择的受信任服务。

## 当前发行限制

只验证了本机 Windows/WSL Docker 路径，原生 helper 仍需 Python 环境。普通 Docker 共享宿主内核，不等同虚拟机隔离。Windows Desktop、干净 Linux 安装、联网依赖下载白名单与完整文件恢复 UI 尚未通过本轮交付验收；恢复材料已保存，取消不会自动回滚。M5 的完整研究、独立验证器及有限自动修订仍需后续实现。
