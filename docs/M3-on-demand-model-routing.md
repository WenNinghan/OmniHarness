# 按需 AI 模型规划：M3 预览

2026-11-08。对应已确认的 `.ai-governance/pre-implementation-on-demand-routing.md`。

在聊天输入框中填写问题，选择 **AI 规划模型**，在右侧确认规划模型和完整请求地址，再点 **生成规划**。界面展示五阶段建议及理由；可分别修改，确认 **用于本次任务** 后发送。普通聊天不会自动规划，单次 AI 规划调用也不算入后续任务的调用预算。规划模型只收到当前输入框问题、已登记候选及用户主动填写的评分和价格，不收到聊天历史；API Key 仅用于身份认证，不放入提示内容。

阶段模型方案随 Run 创建原子冻结，不修改全局阶段设置；运行详情将冻结的计划分配和实际模型调用分开列出。方案可以在同一浏览器会话中显式重新确认后复用；浏览器会话缓存仅包含模型 ID 和配置版本，不缓存问题、理由或密钥。已停用或发生版本变化的模型要求重新选择；在途 Run 不受新草案影响。

## 当前边界

- 规划模型入口目前支持 OpenAI 原生及 OpenAI-compatible；Anthropic、Gemini 暂不能用于这次规划调用，但现有 Agent 阶段和聊天的对应接入不受此限制。
- 当前只将输入框问题发给规划模型，不读取或自动发送聊天历史。规划费用由供应商计费，未知不显示为零。
- 模型目录、AI 理由和用户自填评分不等于能力或价格已经实测；目前不声称 AI 自动选出的方案最便宜或质量最优。
- 规划模型返回截断时提示调整输出上限或缩短问题，不自动重试或修改用户模型设置。
- 当前项目尚无项目级默认模型管理，入口先支持新对话和已有对话。执行阶段仍无项目文件、命令或搜索工具；见 `docs/M3-stage-models.md`。
