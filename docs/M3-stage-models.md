# M3 预览：五阶段模型协作

2026-11-08。本次按已确认的 `.ai-governance/pre-implementation-M3-stage-models.md` 实施。普通聊天仍走原来的单模型路径；新的 Agent 任务采用 `stage-agent-v2`，分别执行思考、规划、任务分配、子任务执行和结构化审查。规划和分配经过结构检查；子任务遵守依赖、最多两个并行，均使用执行阶段绑定的模型。模型调用、预算、结果和已提交检查点事件复用原有持久化与所有权防护。旧 `deep-agents-v2` 与 `stage-agent-v1` 作为独立版本保留。

## 使用

1. 在“模型连接”中为已有 OpenAI-compatible 连接打开“模型目录”，读取后勾选需要的模型并导入。目录不保证模型实际可用。导入的连接使用独立的加密凭据副本，修改原连接后不会自动同步。
2. 在“编排”页面查看五阶段推荐；可按阶段选择模型并保存。可选填写模型阶段评分、同币种输入/输出单价、来源、各阶段最低评分及预计用量；这些是保存在当前浏览器的用户估计，不是测试结论或账单。候选不足、缺少完整依据或币种不同时保留默认模型，不声称最优或省钱。
3. 在对话中选择“Agent 任务”，发送任务。阶段绑定在创建 Run 时冻结，后续配置修改不改变该 Run。运行详情显示实际调用模型和已持久化的阶段产物。

## 已知边界

- 执行 Agent 当前没有项目文件、命令、网络搜索或 MCP 工具；输出不能代表真实代码修改、搜索或测试。工作区沙箱属于后续 M4。
- 审查是模型提供的结构化意见，尚无真实验证器，也未绑定工件版本；不能当作已通过自动测试。
- 各子任务暂时共享执行阶段模型，不能按子任务动态指定不同模型；不自动测评模型质量或对账服务商的实际费用。
- 模型调用结果不明或进程中断导致无法安全重放时，Run 进入待核对；不能承诺所有中断都自动恢复。
- 若回退升级，需使用匹配的旧镜像和升级前数据库备份，不承诺旧应用直接读取升级后的数据库。
